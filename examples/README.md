# Demo: Survey Tools in Research — A Meta-Survey

A self-contained example for the **[umfrage](https://github.com/scinnod/umfrage)**
tool. The topic — survey tools in academic research — makes this a *meta-survey*:
a questionnaire about questionnaires, designed and processed with umfrage itself.

Three fictional respondents from the Duckburg academic universe have already
filled in their responses; the organiser is Prof. Dr. Ludwig von Drake.

## Features demonstrated

| Feature | Where |
|---------|-------|
| `scale` answer type (integer range 1–5) | USG.Q1, REQ.Q1, REQ.Q2 |
| `yes_no` answer type (dropdown) | USG.Q2, REQ.Q3 |
| `choices` answer type with `choices_ref` | USG.Q3, REQ.Q4 |
| `freetext` answer type | USG.Q4, REQ.Q5 |
| `choice_lists` (named, reusable option sets) | `questionnaire_format`, `critical_feature` |
| `required: false` on respondent fields and questions | Email field, USG.Q4, REQ.Q5 |
| Companion metadata for config-free collection | `responses/*_metadata.yaml` |

## Try it yourself

### Validate the questionnaire

```bash
umfrage validate examples/questionnaire.yaml
```

### Regenerate the empty form

```bash
umfrage generate examples/questionnaire.yaml --output-dir examples/
```

The tool auto-detects `config/style.yaml` when run from the repo root; no
`--style` flag is needed unless you want to use a custom style.
Output filenames include a timestamp; rename to replace the committed files.

### Collect the demo responses

```bash
umfrage collect examples/responses/
```

Run from the repo root. The tool auto-detects `config/style.yaml` and picks up
the metadata file in `responses/` automatically — no `--style` or `--config`
flag needed. Output filenames include a timestamp; rename to remove it before
committing.

> **Custom styling** — To adjust colours, fonts, or column widths, copy
> `config/style.yaml` as your starting point, edit it, and pass it via
> `--style path/to/style.yaml`.  The example intentionally omits a style file
> to show that the questionnaire YAML alone is sufficient.
