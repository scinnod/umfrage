# Demo: Survey Tools in Research — A Meta-Survey

A self-contained example for the **[umfrage](https://github.com/scinnod/umfrage)**
tool. The topic — survey tools in academic research — makes this a *meta-survey*:
a questionnaire about questionnaires, designed and processed with umfrage itself.

Three fictional respondents from the Duckburg academic universe have already
filled in their responses; the organiser is Prof. Dr. Ludwig von Drake.

## Features demonstrated

| Feature | Where |
|---------|-------|
| `scale` answer type (integer range 1–5) | META.Q1, META.Q5, META.Q6 |
| `yes_no` answer type (dropdown) | META.Q2, META.Q7 |
| `choices` answer type with `choices_ref` | META.Q3, META.Q8 |
| `freetext` answer type | META.Q4, META.Q9 |
| `choice_lists` (named, reusable option sets) | `questionnaire_format`, `critical_feature` |
| `required: false` on respondent fields and questions | Email field, META.Q4, META.Q9 |
| Companion metadata for config-free collection | `responses/*_metadata.yaml` |

## Try it yourself

### Validate the questionnaire

```bash
umfrage validate examples/questionnaire.yaml
```

### Regenerate the empty form

```bash
umfrage generate examples/questionnaire.yaml \
        --style examples/style.yaml \
        --output-dir examples/
```

The output filenames include a timestamp. Rename them to replace the committed
files, if desired.

### Collect the demo responses

From the repo root (style resolved via `--style`):

```bash
umfrage collect examples/responses/ --style examples/style.yaml
```

Or from the `examples/` directory, where `style.yaml` is auto-detected from the
current working directory:

```bash
cd examples/
umfrage collect responses/
```

The metadata file in `responses/` is picked up automatically — no `--config` flag
needed. The tool aggregates the three pre-filled responses into a single result
spreadsheet. Rename it to remove the timestamp before committing:

```bash
mv examples/responses/results_survey-tools-in-research-a-meta-survey_*.xlsx \
   examples/responses/results_survey-tools-in-research-a-meta-survey.xlsx
```
